# STEMLY — образовательная платформа STEM

Современная платформа онлайн-курсов по направлениям **наука, технологии, инженерия и математика**, построенная на **Laravel 12**. Включает каталог курсов с любой глубиной вложенности категорий, видео- и текстовые уроки, материалы для скачивания (PDF, Word, Excel и др.), тесты с автопроверкой, систему комментариев и лайков, личный кабинет с прогрессом и навыками, именные сертификаты с публичной проверкой и полноценную админ-панель.

---

## Технологии

- **Laravel 12** (PHP 8.2+)
- **Blade** + **Tailwind CSS v4** (CSS-first `@theme`) + **Alpine.js**
- **Vite 6** для сборки фронтенда
- **MySQL** (можно заменить на PostgreSQL/SQLite)
- **barryvdh/laravel-dompdf** — генерация PDF-сертификатов с поддержкой кириллицы
- **intervention/image** — обработка изображений
- **spatie/laravel-translatable** — многоязычный контент (RU / KK / EN)

---

## Требования

- PHP **8.2** или новее, с расширениями: `pdo_mysql`, `mbstring`, `gd`, `zip`, `bcmath`, `fileinfo`
- **Composer** 2.x
- **Node.js** 18+ и **npm**
- **MySQL** 8+ (или MariaDB 10.4+)

## Установка

```bash
# 1. Установить PHP-зависимости
composer install

# 2. Установить JS-зависимости
npm install

# 3. Создать файл окружения
cp .env.example .env

# 4. Сгенерировать ключ приложения
php artisan key:generate
```

### Настройка базы данных

Создайте базу данных, например `stem_lms`, и пропишите доступы в `.env`:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=stem_lms
DB_USERNAME=root
DB_PASSWORD=ваш_пароль
```

### Миграции и тестовые данные

```bash
# Создать таблицы и наполнить демо-контентом
php artisan migrate --seed

# Создать символическую ссылку для загруженных файлов
php artisan storage:link
```

> Если база уже создавалась ранее и нужно пересоздать её с нуля (например, после изменения структуры), используйте `php artisan migrate:fresh --seed` — команда удалит все таблицы и наполнит базу заново.

### Сборка фронтенда и запуск

```bash
# Собрать ассеты (production)
npm run build

# Запустить локальный сервер
php artisan serve
```

Откройте **http://127.0.0.1:8000**

> Для разработки вместо `npm run build` можно запустить `npm run dev` в отдельном терминале (горячая перезагрузка ассетов).

## Загрузка больших видео

Плеер поддерживает как ссылки на YouTube/Vimeo, так и прямую загрузку видеофайлов (до **1 ГБ**) и материалов (до **50 МБ**). Чтобы загрузка больших файлов работала, увеличьте лимиты в `php.ini`:

```ini
upload_max_filesize = 1024M
post_max_size = 1024M
max_execution_time = 600
memory_limit = 512M
```

После изменений перезапустите PHP/веб-сервер.

## Основные возможности

### Для пользователей
- Регистрация и вход (фамилия используется в сертификатах)
- Каталог курсов с поиском, фильтрами по уровню и сортировкой
- Категории и подкатегории **любой глубины вложенности**
- Видео-уроки (встроенные плееры YouTube/Vimeo или загруженные файлы), текстовые уроки, материалы для скачивания
- Бесплатные превью-уроки для незаписанных пользователей
- Отслеживание прогресса по урокам и курсам
- Тесты с автопроверкой (один или несколько правильных ответов) и подробным разбором
- Комментарии и лайки к курсам
- Личный кабинет: курсы в процессе, завершённые, приобретённые навыки, рекомендации
- Именные сертификаты при прохождении курса на 100% + скачивание PDF
- Публичная проверка подлинности сертификата по номеру

### Для администратора
- Дашборд со статистикой и графиком записей за 14 дней
- Управление курсами: разделы, уроки (видео/статья), материалы, привязка тестов
- Конструктор категорий с неограниченной вложенностью
- Конструктор тестов с вопросами и вариантами ответов
- Модерация комментариев: ответы от имени команды, скрытие, удаление
- Управление пользователями: блокировка с указанием причины, назначение/снятие прав администратора
- Конструктор меню (шапка и подвал) с вложенными пунктами
- Настройки платформы: название, слоган, контакты, данные подписанта сертификатов

### Безопасность доступа
- Неавторизованные пользователи **не могут** проходить курсы и получать сертификаты — доступны только публичные страницы каталога, превью-уроки и проверка сертификата
- Заблокированные пользователи автоматически выходят из системы при попытке действия

## Многоязычность (RU / KK / EN)

Платформа полностью локализована на трёх языках: **Русский** (по умолчанию), **Қазақша** и **English**.

**Интерфейс (статика).** Все надписи вынесены в языковые файлы `lang/ru`, `lang/kk`, `lang/en` (`app.php`). Переключатель языка находится в шапке сайта. Выбранный язык запоминается в сессии и в профиле пользователя; middleware `SetLocale` применяет его к каждому запросу. Язык по умолчанию и фолбэк задаются в `.env` (`APP_LOCALE`, `APP_FALLBACK_LOCALE`).

**Контент из БД (динамика).** Через `spatie/laravel-translatable` переводятся: названия и описания курсов, разделов, уроков, материалов, тестов (вопросы, пояснения, варианты ответов), категорий, пунктов меню, а также слоган и текст в подвале. Эти поля хранятся в формате JSON по языкам. На сайте контент показывается на текущем языке с автоматическим откатом на язык по умолчанию (RU), если перевод отсутствует.

**Редактирование переводов в админке.** В каждой форме (курсы, категории, разделы, уроки, тесты, меню, настройки) переводимые поля снабжены вкладками **RU / KK / EN** — заполняйте нужные языки. Обязателен только язык по умолчанию; остальные можно добавить позже.

**Список языков** настраивается в `config/locales.php` — чтобы добавить новый язык, допишите его код в массив `available`, создайте каталог `lang/{код}/app.php` и при необходимости расширьте `Setting::TRANSLATABLE`.

> Демо-данные засеяны на всех трёх языках для категорий и настроек; курсы, уроки и тесты заполнены на русском (служит фолбэком) — остальные языки добавляются через админ-панель.

## Структура проекта

```
app/
  Http/
    Controllers/
      Auth/            — регистрация и вход
      Frontend/        — публичная часть и кабинет
      Admin/           — админ-панель
      Concerns/        — трейт обработки переводов
      LocaleController — переключение языка
    Middleware/
      SetLocale.php    — применение языка к запросу
  Models/              — 18 моделей Eloquent (с HasTranslations)
  Helpers/             — вспомогательные функции (setting, locales, …)
config/
  locales.php          — список языков платформы
  translatable.php     — настройки переводов (фолбэк RU)
database/
  migrations/          — 19 миграций
  seeders/             — демо-данные (многоязычные)
lang/
  ru/ kk/ en/          — строки интерфейса
resources/
  views/
    components/i18n-field.blade.php — поле с вкладками языков
    …                  — Blade-шаблоны (фронтенд + админка)
  css/app.css          — дизайн-система (Tailwind v4 @theme)
  js/app.js            — Alpine.js
routes/web.php         — все маршруты
```

## Дизайн-система

Тема **«Blueprint Observatory»**: глубокий тёмно-синий фон, сигнальный лаймовый акцент, бирюзовый и коралловый дополнительные цвета. Шрифты: **Sora** (заголовки) и **Manrope** (текст). Все цвета и утилиты вынесены в `resources/css/app.css`.
